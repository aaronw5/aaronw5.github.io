# aaronw5.github.io

Personal site. Static HTML/CSS, no build step.

## Deploy
1. Create a repository named `aaronw5.github.io` on GitHub (public).
2. Copy these files into it and push to `main`.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site is live at https://aaronw5.github.io within a minute or two.

## Update
- Text: edit `index.html`.
- CV: replace `assets/Aaron_Wang_CV.pdf`.
- Paper figures: drop a file into `assets/figs/` and point the `<img class="fig">` at it. Placeholders are the `.svg` files.
- Photo: replace `assets/profile.jpg` (square, ≥600 px).
